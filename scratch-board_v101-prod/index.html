📝 ScratchBoard Plugin Standalone Preview

Decoupled & Zero Dependency

ScratchBoard

⚠️ Backup your board regularly. Clearing browser data will erase it.
Explainer: Use the ScratchBoard to save snippets. Quick notes persist line-by-line in browser storage.

Testbench Operations

  • Board Canvas: Displays persistent notes line-by-line. Renders on load and updates immediately when changes are committed.
  • Button 1 (Save): Persists textarea content to localStorage['scratchboard_cache'] and live-updates the Canvas.
  • Button 2 (Choose File): Selects a local .txt notes file for staging.
  • Button 3 (Import): Ingests the chosen file, strips formatting/blank lines, and updates the Canvas.
  • Button 4 (Export): Generates an instant, timestamped .txt download of all active board notes.
  • Developer Console: Programmatic cache clearing via window.clearScratchboardCache() or manual re-bootstrap via window.init_scratchboard().
